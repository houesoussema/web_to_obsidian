# Obsidian Web Crawler (Playwright Edition)

This is a sophisticated web crawler designed to capture fully rendered web content and save it into Obsidian-formatted Markdown files. It uses Playwright, a browser automation library, to handle modern, JavaScript-heavy websites and can even work with sites that require you to be logged in.

## Features

- **JavaScript Rendering:** Captures the full content of websites, including text and images generated by JavaScript.
- **Persistent Authentication:** Can reuse your browser's cookies to access content behind a login wall.
- **Intelligent Content Extraction:** Automatically identifies and extracts the main article content, removing clutter like navigation, ads, and footers.
- **Rich Metadata:** Extracts metadata from the page, such as title, author, and publication date, and saves it as YAML frontmatter.
- **Flexible Configuration:** All settings are configurable via command-line arguments.
- **Obsidian-Ready:** Creates clean, well-formatted Markdown files with wikilinks, ready to be dropped into your Obsidian vault.

## Prerequisites

- Python 3.8+
- The dependencies listed in `requirements.txt`.

## Setup

1.  **Clone the repository and install dependencies:**

    ```bash
    pip install -r requirements.txt
    ```

2.  **Install browser binaries for Playwright:**

    This is a one-time setup that downloads the necessary browser engines.

    ```bash
    playwright install
    ```

3.  **(Optional) Authentication Setup:**

    To scrape content from websites where you need to be logged in, the scraper can reuse the cookies and session information from your regular web browser.

    -   **Find your browser's user data directory:**
        -   **Windows (Chrome):** `C:/Users/YourUser/AppData/Local/Google/Chrome/User Data`
        -   **macOS (Chrome):** `~/Library/Application Support/Google/Chrome`
        -   **Linux (Chrome):** `~/.config/google-chrome`
    -   When you run the scraper, you will pass this path using the `--user-data-dir` argument.

    **Note:** The first time you run the scraper with authentication, it may open a browser window for you to log in. After that, it should remember your session.

## Usage

The script is run from the command line, with the start URL and your Obsidian vault path as the two required arguments.

### Basic Example

```bash
python advanced_scraper.py "https://example.com" "/path/to/your/obsidian/vault"
```

### Advanced Example with Authentication

This example scrapes a members-only area of a website, runs the browser in headful mode (so you can see what it's doing), and saves the files to a specific folder in your vault.

```bash
python advanced_scraper.py "https://members.example.com/articles" "/path/to/your/obsidian/vault" --user-data-dir "/path/to/your/chrome/profile" --obsidian-folder "Clippings/Members Content" --headless=false
```

### Command-Line Arguments

-   `start_url`: The URL to begin crawling from.
-   `vault_path`: The absolute path to your Obsidian vault.
-   `--obsidian-folder`: (Optional) The folder within your vault to save the scraped files. Defaults to `99-Clippings/Web Scrapes`.
-   `--user-data-dir`: (Optional) The path to your browser's user data directory to enable authentication.
-   `--max-pages`: (Optional) The maximum number of pages to scrape. Defaults to 50.
-   `--delay`: (Optional) The delay in seconds between page fetches. Defaults to 1 second.
-   `--headless`: (Optional) Whether to run the browser in headless (no UI) mode. Defaults to `true`. Use `--headless=false` to watch the browser work.

## How It Works

The scraper starts at the `start_url` and uses a breadth-first search (BFS) strategy to find and visit new links, staying within the same domain. For each page it visits, it:

1.  Waits for the page to fully render, executing any JavaScript.
2.  Extracts the main content and metadata.
3.  Converts the content to Markdown.
4.  Saves it as a `.md` file with YAML frontmatter in your Obsidian vault.

This process continues until it has visited `max_pages` or there are no more new links to find on the domain.
